# Devgotchi DB Setup Power

A reusable Kiro Power designed to bootstrap a PostgreSQL database environment using Docker and run Drizzle ORM schema migrations with a single execution step.

Built as part of the Kiro University Challenge (Bonus Lesson 2).

## Requirements
- Docker & Docker Compose
- Bun runtime

## Usage
Add this power to your project's `.kiro/powers/` directory or reference it directly in your Kiro workspace configuration to automate database setup.
